Política de Privacidade

Última atualização: 29 de setembro de 2026

O app "BuyThisOne" é uma ferramenta de uso pessoal que envia vídeos para o canal do YouTube do próprio desenvolvedor, usando os Serviços de API do YouTube (YouTube API Services).

Dados acessados

O app pede apenas a permissão youtube.upload, usada exclusivamente para enviar vídeos e definir título, descrição, tags e visibilidade deles no canal autorizado. Nenhum outro dado da conta Google ou do YouTube é lido.

Armazenamento e compartilhamento

O token de acesso fica salvo apenas no computador de quem autorizou o app. Nenhum dado é enviado a servidores próprios, vendido ou compartilhado com terceiros. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Termos do YouTube e do Google

Ao usar este app você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.
